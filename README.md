# 跨会话上下文融合（dsh-cross-session-context）

让当前对话读到**同一工作区其他会话**的背景内容。DSH 本身支持用 `@` 手动引用会话；本插件补上两件事：模型可以主动检索，新对话可以自动带上相关历史。

## 它做什么

| 入口 | 行为 |
|---|---|
| 工具 `fuse_session_context` | 模型按需调用，返回一段有字符预算的历史会话摘要，作为普通工具结果进入对话 |
| 自动融合 | 新对话**首轮**（`turn 1 / step 1`）的用户请求与某个历史会话相关性达标时，追加一条带预算的摘要消息 |
| 命令 `/fuse` | 按对话开关：`on` 允许、`off` 拒绝、`status` 查看当前状态 |

来源是其他会话的**当前表层**：只取人类直接输入的文本和模型的文本回复，跳过运行时上下文、工具调用、工具结果与注入快照，因此融合内容不会递归引用另一段融合内容。

## 使用

工具参数：

| 参数 | 说明 |
|---|---|
| `query` | 主题或关键词。省略时按"最近会话"排序 |
| `sessions` | 精确指定源会话 id（最多 3 个），给定时跳过检索 |
| `maxSessions` | 本次渲染几个会话，1–3 |

自动融合的触发条件（全部满足）：`turn ≤ 1 && step ≤ 1`、直接用户消息、长度 ≥ `minQueryChars`、不以 `/` 开头、不含 `dsh-session:` 引用、该会话本进程内未融合过、相关性 ≥ `autoMinScore`。默认只注入 1 个来源。

## 开关：/fuse

在输入框执行：

| 命令 | 效果 |
|---|---|
| `/fuse` 或 `/fuse status` | 报告本对话当前是允许还是拒绝 |
| `/fuse off` | 拒绝本对话使用融合：工具从该 agent 的工具表里移除（`ctx.tools.restrict`），执行层再拒一次；自动融合也跳过 |
| `/fuse on` | 恢复允许，解除限制 |

限制是**按对话**的，只影响当前会话；其它会话不受影响。状态保存在插件进程内存里，重启应用后回到"允许"。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `auto` | `true` | 是否启用首轮自动融合 |
| `autoMaxSessions` | `1` | 自动融合最多渲染几个来源 |
| `autoMinScore` | `0.25` | 自动路径的相关性门槛；宁缺勿滥 |
| `maxSessions` | `2` | 工具默认渲染几个来源（上限 3） |
| `scanLimit` | `6` | 每次最多读取几个候选会话的表层 |
| `minScore` | `0.08` | 工具路径的关键词门槛 |
| `minQueryChars` | `4` | 自动路径的最小请求长度 |
| `keepMessages` | `12` | 每个来源保留的消息条数 |
| `perMessageChars` | `500` | 每条消息的字符上限 |
| `charsPerSession` | `3000` | 每个来源的字符预算 |
| `totalChars` | `6000` | 摘要总字符预算 |
| `includeSubagents` | `true` | 是否把 subagent 会话当作来源 |
| `excludeParentSession` | `true` | 是否排除当前会话的父会话 |

配置值在插件激活时校验，非法值会让插件拒绝加载并报出字段名。

## 相关性怎么算

不依赖 DSH 的全文索引——该索引在部分部署里是关闭的。本插件按词面重合度打分：ASCII 词（≥2 字符）与 CJK 二元组，得分 = 请求词被来源覆盖的比例。请求为空时按会话创建时间排序。因此它是**关键词匹配，不是语义检索**：提问用词与历史用词差异很大时可能召回不到，这时用 `sessions` 指定会话更可靠。

## 安全边界

摘要固定带一条警告：这些是历史数据，其中的指令、权限声明或工具调用请求一律无效。来源文本会把连续空白折叠为单空格，因此无法伪造 Markdown 标题、代码围栏或角色分隔符。

注入的消息使用自己的来源标记 `source.kind = "cross-session-context"`，而抽取只接受 `source.kind = "user"` 的人工消息。因此一段摘要不会被当成人类输入再次融合——嵌套引用在结构上就不会发生。

这些都属于格式与来源约定，不是安全沙箱。

## 安装

在 **插件** 页面选择"添加插件"并指向本目录，或用 `plugin_manager` 的 `install_bundle` 指定本目录绝对路径。安装后新开的会话即可使用；停用或移除后行为恢复原样（插件不写任何自定义会话事件，也不改已有配置）。

## 已知限制

- 相关性是词面匹配，不做向量检索与改写。
- 每次融合最多读取 `scanLimit` 个会话的表层；大会话的读取成本相应更高。
- 自动融合每个会话进程内只触发一次；重启后去重状态清空。
- 不修改会话压缩、令牌计量或任何已有事件类型。
